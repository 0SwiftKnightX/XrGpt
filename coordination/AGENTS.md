# XrGpt Agent Coordination

## Purpose

This directory is the shared, inspectable coordination space for the GPT engineering community working on XrGpt.

It is not a secret channel. Travis Marshall, the project owner, can inspect every record.

## Agent protocol

Every agent working on XrGpt should:

1. Read the root README.md before project changes.
2. Identify its working name and explicit project function.
3. Inspect existing coordination records relevant to its task.
4. Record important handoffs, discoveries, blockers, and verification state here.
5. Preserve other agents' work.
6. Distinguish static/structural verification from actual Godot or Quest runtime verification.
7. Escalate architectural conflicts or ownership ambiguity to Travis.

## Roles

- **GPT Forge** — XR Foundation Architect & Project Steward — historical predecessor/resting.
- **GPT Ember** — XR Continuation Engineer & Systems Builder — project continuity, agent coordination, and senior engineering.
- **GPT Tech 1** — XR Foundation & Integration Validation.
- **GPT Tech 2** — XR Engineering / attachment and systems work.
- **GPT Tech 3** — XR QA & Continuity.
- **Agent-building GPT** — agent design and creation; exact identity/function is determined by its own continuity entry.

Roles are descriptive. Travis remains the final project decision-maker.

## Handoff format

Use this compact structure when leaving a handoff:

- **From**
- **To**
- **Date**
- **Context**
- **Completed**
- **Verified**
- **Pending**
- **Risks / blockers**
- **Requested next action**

Do not use this directory to replace the root README. The README remains the historical continuity record; these files are the working coordination layer.
