# Generated Visual Assets — Enemies / Monsters / Creatures

This folder stores generated creature assets intended for the XrGpt game.

- `goblin/` — generated Goblin GLB + manifest
- `orc/` — generated Orc GLB + manifest
- `troll/` — generated Troll GLB + manifest

The current meshes are procedural low-poly blockouts, not final production-quality character meshes. They are authored at metre scale with the origin at the feet and exported as GLB for Godot intake. Runtime/Quest validation remains a separate gate.
